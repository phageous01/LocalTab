# Original examples

[简体中文](README.zh-CN.md) · [Back to LocalTab](../README.md)

These short exercises are generated specifically for LocalTab and covered by the
repository's MIT license. They contain no imported songs or audio.

| File | Instrument | Purpose |
| --- | --- | --- |
| [five-string-bass.musicxml](five-string-bass.musicxml) | Five-string bass | Rests, tuning, ties and dead notes |
| [guitar-chords.musicxml](guitar-chords.musicxml) | Six-string guitar | Multiple notes at one position |

Start LocalTab, select **English** in the top bar, click **Import score**, and choose
either file. Add your own MP3 to try synchronization, or use the basic synthesized
preview without a recording.

To regenerate these files and the synthetic test fixture, run from the repository root:

```sh
python scripts/generate_examples.py
```
